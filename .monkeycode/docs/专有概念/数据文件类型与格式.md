# 数据文件类型与格式

## 概述

系统支持 6 种 Excel 文件类型导入。文件类型通过 `Excel.identifyFileType()` 根据表头关键词**自动识别**，无需用户手动选择。

**V3.3**：打卡/请假/加班/出差/漏打卡的必含与加分表头改为 **OA 字段映射**（`settings.oa_field_map`）中的别名列表，支持精确 + 模糊匹配；排班仍按 Sheet 名识别。规格见 `.monkeycode/specs/v3.3-import-flexibility/`。

## 类型识别规则

识别流程：
1. `_findHeaderRowIndex` 在前 20 行内定位表头行（命中关键词 `申请人|请假类型|加班起止|出差起止|忘打卡|漏打卡|考勤号码|考勤号`，否则取填充单元格最多的行）
2. `uniquifyHeaders` 去空白并给重复表头加 `#2` 后缀
3. 读取 Field Map（缺省用内置默认别名）
4. 必含别名全部 `headerExists`（得分 >= 40）→ 有效类型；加班另有 `requiredAlt`（`开始时间` + `结束时间`）备选
5. 加分别名命中越多 → 得分越高 → 优先级越高
6. 无匹配 → `unknown` 类型，显示表头供用户确认

### 1. 打卡记录 (punch)

**必含**：`考勤号码`、`签到时间`

**加分**：`签退时间`、`迟到时间`、`部门`、`日期`、`上班时间`、`下班时间`

**标准化字段**（`RECORD_SCHEMA.punch`，不读 Field Map 的 isSelf/subject）：
```
employeeNo, customNo, name, date, period, scheduleStart, scheduleEnd,
signIn, signOut, lateMinutes, earlyMinutes, absent,
overtimeHours, workHours, department,
isWeekday, isWeekend, isHoliday, weekdayOT, weekendOT, holidayOT
```

### 2. 请假记录 (leave)

**必含**：`请假类型`、`开始日期`

**加分**：`结束日期`、`请假天数`、`申请人`、`申请部门`、`是否本人`、`请假人员`

**标准化字段**：
```
applicant, department, leaveType, startDate, endDate,
leaveDays, leaveHours, reason, isSelf, subject
```

**特殊处理**：结束日期为空时按开始日期处理（单日请假）。`subject`：本人申请取申请人；代申请取「请假人员」。

### 3. 加班记录 (overtime)

**必含**：`加班起止时间`；或备选 `开始时间` + `结束时间`（`TYPE_IDENTIFY.overtime.requiredAlt`）

**加分**：`申请人`、`申请部门`、`加班内容`、`是否本人`、`加班人员`、`小时`

**标准化字段**：
```
applicant, department, startTime, endTime, overtimeHours, content, isSelf, subject
```

**特殊处理**：通过 `overtimeHours` 字段获取小时数，匹配到考勤日时追加到当日加班。`subject` 规则同请假。

### 4. 出差记录 (travel)

**必含**：`出差起止日期`

**加分**：`申请人`、`目的地`、`出差事由`、`出差人员`、`是否本人`

**标准化字段**：
```
applicant, department, destination, travelers,
startDate, endDate, travelType, reason, isSelf, subject
```

**特殊处理**：日期字段可能为"2026-02-01至2026-02-03"格式，需按 `-`、`~`、`至`、`到` 分割。`subject` 取出差人员名单（代申请）或申请人。

### 5. 漏打卡记录 (miss_punch)

**必含**：`忘打卡日期`

**加分**：`申请人`、`忘打卡人员`、`未打卡时间`、`事由`

**标准化字段**：
```
applicant, department, missDate, missPerson, missTime, cardTime, reason, isSelf, subject
```

**特殊处理**：`missPerson` 与 `subject` 同源（代申请取忘打卡人员）。

### 6. 排班表 (schedule)

排班文件不通过表头识别，而是通过 **Sheet 名称匹配**：Sheet 名符合 `^\d{1,2}月$` 格式（如 `1月`、`12月`）即为排班表。

**特殊处理**：
- 通过单元格**填充色**判断休息日：有填充色 = 休息，无填充色 = 上班
- 排班区间按 `(周一~周日, 周一~周日)` 格式解析
- 入库时**按员工展开**：每条排班 × 员工数量 → 每人每月一条记录

## 数字日期/时间格式

Excel 中日期/时间可能以数字形式存储：
- **日期数字** (如 `44971`) → 通过 `XLSX.SSF.parse_date_code()` 转为 `YYYY-MM-DD`
- **时间小数** (如 `0.729166667`) → 转为 `HH:MM`（乘 24 得小时，小数部分乘 60 得分钟）

## 去重策略

导入时检查 `raw_files` 表，同名文件已存在则跳过。同一类型文件导入时先清空对应表再写入（打卡数据除外，打卡导入会触发 `Matcher.syncEmployees()` 重建员工表）。

## V3.3 OA 字段映射

配置入口：规则设置 →「OA 字段」Tab（请假 / 漏打卡 / 加班 / 出差 / 打卡）。

持久化：`settings.oa_field_map`。实现：`client/src/shared/fieldMap.js`。

匹配得分：精确 100；去语气词后相等 80；前后缀包含 60；压缩后前后缀 40。识别阈值 40；自动学习阈值 60（把实际表头插入别名列表头部）。

「视为本人」默认：本人 / 是 / Y / YES / TRUE / 是本人。「视为帮他人」默认：非本人 / 否 / N / NO / FALSE / 帮他人 / 代申请 / 其它 / 其他 等。空 `isSelf` 按帮他人处理，实际人员为空则回退申请人。

`isSelf` 默认别名含 `是否本人` / `本人申请` / `选项` / `是否为本人` / `申请类型`。OA 把该列叫「选项」时，预览显示本人或其它。

重复「申请人」列：从左到右，第 1 列是填单人，第 2 列是被代申请人。是否本人 = 本人 → `subject` 取第 1 列；是否本人 = 其它 → 取第 2 列。

导入预览表头展示中文名（`FIELD_LABELS`），与规则设置「OA 字段」Tab 一致。
